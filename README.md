# Booking & Accommodation Platform

A full-stack, high-performance accommodation booking platform built with an asynchronous architecture.

## Tech Stack
- **Backend:** Python 3.11, Django 5.0, Django REST Framework, Daphne (ASGI), Channels (WebSockets)
- **Task Queue & Cache:** Celery, Redis
- **Database:** PostgreSQL
- **Payments:** Stripe API & YooKassa SDK
- **Frontend:** React, TypeScript, Vite
- **DevOps & QA:** Docker, Docker Compose, Nginx, Ruff, PyTest
